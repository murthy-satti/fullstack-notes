# HTML Text, Headings, and Lists

This overview links to focused lessons about the HTML elements used to
structure written content. Choose elements for their meaning; use CSS for
visual appearance.

## Learn these topics

- [Text and paragraphs](text-and-paragraphs.md): paragraphs, quotations, and
  preformatted text.
- [Headings](headings.md): heading levels and a clear document hierarchy.
- [Lists](lists.md): ordered, unordered, and description lists.
- [Inline text semantics](inline-text-semantics.md): emphasis, code, edits,
  and other meaning within a line.

## How they work together

Headings introduce sections, paragraphs contain prose, lists group related
items, and inline elements express meaning within text. For example, an
instruction page can use an `<h1>` for its title, `<h2>` for each step,
`<p>` for explanations, and `<ol>` when the order matters.
