# HTML Links and Media

Use HTML links to navigate and media elements to provide visual or audio
content. Each has its own attributes and accessibility requirements.

## Focused lessons

- [Links](links.md): destinations, fragments, email and phone links, and
  safe new-tab behavior.
- [Images](images.md): alternative text, responsive sources, and intrinsic
  dimensions.
- [Audio and video](audio-and-video.md): sources, playback controls, captions,
  and accessible alternatives.

## Core idea

A link performs navigation; a button performs an action on the current
interface. Media elements describe content that the browser can render or
play. Choose descriptive names and alternatives so people using assistive
technology can understand the purpose and meaning.

## Check your understanding

1. When should an image use empty `alt` text?
2. Which element should be used for an action rather than navigation?
3. What HTML element connects captions to a video?
