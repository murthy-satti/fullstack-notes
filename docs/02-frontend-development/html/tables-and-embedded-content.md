# HTML Tables and Embedded Content

Tables represent relationships between row and column values. Embedded
content places a separate resource, such as another document, inside the
current page. Learn each separately:

- [Tables](tables.md): captions, headers, rows, cells, and accessible
  relationships.
- [Embedded content](embedded-content.md): iframes, titles, permissions, and
  security considerations.

Use a table for data that has meaningful rows and columns, not to position
the page layout. Embed another page only when it adds real value and can be
used accessibly.
