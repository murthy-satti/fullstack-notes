# Next.js Link and Image Components

Next.js provides React components for application navigation and image
delivery. They build on browser features and add framework-specific
behavior.

- [`Link`](link-component.md): internal navigation and prefetching.
- [`Image`](image-component.md): responsive image dimensions and
  optimization.

These components still require familiar web fundamentals: semantic
navigation, descriptive link text, appropriate alternative text, and
responsive layouts.
