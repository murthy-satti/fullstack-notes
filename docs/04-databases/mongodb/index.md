# MongoDB

MongoDB stores BSON documents in collections. This module is a focused learning path through its data model, query language, development tools, performance, consistency, security, and operations. It is divided into short lessons so each subject can be studied on its own.

## Suggested learning path

1. Start with [databases and collections](databases-and-collections.md), [BSON documents and types](bson-documents.md), and [ObjectIds](objectid-and-identifiers.md).
2. Practice [query operators](query-operators.md), [projection and pagination](projection-sort-pagination.md), [inserts](insert-operations.md), [updates](update-field-operators.md), [upserts](upserts-replacements.md), and [deletes](delete-operations.md).
3. Learn [data modeling](data-modeling-and-validation.md), [schema validation](schema-validation.md), [index design](indexes-and-performance.md), and [query plans](query-plans-explain.md).
4. Study [aggregation pipelines](aggregation.md), then work through the dedicated lessons on stages, expressions, joins, facets, and output.
5. Use [Atlas](atlas.md), [Compass](compass.md), [mongosh](mongosh.md), and [driver connections](connections.md) to practice with a development deployment.
6. Finish with consistency, transactions, replication, sharding, change streams, security, networking, backup, and operations.

## Topics beyond the core path

The navigation also covers collation, geospatial queries, views, time-series collections, TTL indexes, capped collections, GridFS, MongoDB Search and Vector Search, storage engines, journaling, import/export, and migration.

Start with [Database Fundamentals](../database-fundamentals.md) and compare this document model with [PostgreSQL](../postgresql/index.md). Choose designs from workload and consistency needs; flexible schema still benefits from deliberate contracts and indexes.
